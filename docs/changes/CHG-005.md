# CHG-005: OrgLens Studio als interaktive Frontend-Demo

06.11.2026 · Nutzerauftrag: hochwertigeres Look-and-Feel, nur Frontend entwickeln und nach GitHub pushen.

[REQ-16](../requirements/REQ-16.md) wird als separate statische React-App umgesetzt. Acht navigierbare Arbeitsbereiche ersetzen den langen Bericht als Pages-Einstieg: Überblick, Quellen, Findings, Innen-/Außensicht, Prozesse, Empfehlungen, Zielbild und Berichtsvorschau. Helle blaue Gestaltung, interaktives STAR-Radar, responsive Navigation und manuelle Editoren; Änderungen am synthetischen Projekt bleiben im aktuellen Browser-Tab.

Der bestehende lokale Next.js-/SQLite-PoC bleibt unverändert. Kein öffentlicher Upload, Login oder Gatewayzugriff. Der alte Beispielbericht bleibt unter report.html. Root und /docs enthalten identische Einstiege und inhaltsadressierte Assets; keine Änderung an der bisherigen Pages-Konfiguration nötig.

Architektur: [ADR-002](../adr/ADR-002.md). Prüfung: [CHG-005 QA](../qa/CHG-005.md). Übergabe und Rücknahme: [REL-002](../releases/REL-002.md). Fachliche Abnahme durch den Nutzer steht aus.
