# CHG-003: GitHub-Push und statische Berichtsdemo

Nutzer möchte ohne lokale Node.js-Installation auf GitHub arbeiten und den PoC pushen. Vollständiger Backendbetrieb ist auf GitHub Pages nicht möglich. Lokale App bleibt unverändert; scripts/build-pages.ts generiert ausschließlich aus dem fiktiven Demo-Projekt eine ausdrücklich als solche gekennzeichnete Pages-Berichtsdemo nach docs/index.html. Kein Zugriff auf lokale Projekte/Auth/Gateway.

Betroffene Dateien: neues Generierungsskript, npm-Skript build:pages, docs/index.html, docs/.nojekyll sowie README und Release-/Projektstanddokumentation. Kein Backend-/Datenmodellwechsel. Seiteninhalt und Offline-Interaktionen basieren auf dem bereits geprüften Report-Renderer aus CHG-002. Neue visuelle Änderung ist der ausdrückliche Demo-Hinweis.

Prüfungen und Ausführung: [REL-001](../releases/REL-001.md). Push wurde vom Nutzer ausdrücklich autorisiert. Repository-Sichtbarkeit wird nicht durch den Agenten geändert. Tatsächlicher Pages-Deploymentstatus und Live-Smoke-Test bleiben bis zur Aktivierung durch den Nutzer offen.
